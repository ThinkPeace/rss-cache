UI style guides

This is a collection of preserved UI style guides a.k.a. interface guidelines from various companies, starting from the early 1980s and continuing to today.

Many of the PDFs have been floating around, but I collected them in one place. Within each set, I tried to group them depending on themes and eras, and highlight the most important ones. Some required more effort to find, I scanned a few myself, plus also created standalone mirrors of various minisites. Some of the mirrors were lightly cleaned up to make their consumption easier – stuff like pixellating images better, inlining images instead of linking to them, or fixing YouTube embeds. Enjoy!

  • Amiga

    (Commodore) Amiga was a multimedia personal computer particularly popular in the 1980s and 1990s in Europe. Its GUI was called Intuition and/or Workbench.

  • Amiga User Interface Style Guide

  • Android

    Android is a mobile operating system and a rival to iOS. The first style guide I could locate was in 2012.

  • Android Design
  • Material Design v1
  • Material Design v2
  • Design for Android

  • BeOS

    BeOS was an operating system released in the second half of the 1990s. A proper HIG for BeOS never materialized despite numerous promises. These “preliminary and incomplete” guidelines have been extracted from the BeOS R4.5 CD.

  • BeOS User Interface Guidelines

  • Black­Berry

    BlackBerry was a beleagured maker of mobile handsets.

  • BlackBerry Wireless Handheld User Interface Style Guide
  • BlackBerry PlayBook Tablet UI Guidelines
  • BlackBerry Smartphones UI Guidelines
  • BlackBerry 10 UI Guidelines

  • CDE

    Common Desktop Environment (CDE) is a desktop environment for Unix machines, using (and eventually merging with) OSF/Motif widgets.

  • OSF/Motif Style Guide
  • Common Desktop Environment: Style Guide and Certification Checklist

  • CUA

    Common User Access (CUA) is a late 1980s standard for user interfaces that influenced Windows and OS/2.

  • System Application Architecture: Common User Access
  • Object-Oriented Interface Design: IBM Common User Access Guidelines

  • DECwindows XUI

    A Unix interface built using X Window System by Digital Equipment Corporation. This style guide was reverse engineered from a proprietary e-book format.

  • XUI Style Guide

  • GEM/TOS

    Graphics Environment Manager (GEM) is a 1980s operating system/GUI. It was well-known by users of the Atari ST computers, known in these circles as TOS. Both of the websites mirrored are (obviously) more modern, but seem to contain vintage information, hence the confusing “1980s website” label.

  • GEM User Interface Guidelines
  • The documentation for TOS

  • GNOME

    GNOME is a desktop environment for Linux and BSD operating systems. Note that the versioning number of these guidelines is very confusing.

  • GNOME Human Interface Guidelines
  • GNOME Human Interface Guidelines
  • GNOME Human Interface Guidelines

  • Google VR/AR

    Style guides for Google’s early VR and AR efforts.

  • Glass Developers: Design
  • Designing for Google Cardboard

  • iOS and iPadOS

    iOS (previously iPhone OS) is Apple’s mobile operating system for iPhone smartphones and their siblings.

  • iPhone Human Interface GuidelinesCovers the skeuomorphic era of iOS 1–6
  • iOS Human Interface GuidelinesCovers iOS 7+
  • iPad Human Interface Guidelines
  • Apple Human Interface Guidelines

  • Java

    Java is a programming language, which comes equipped with JFC (Java Foundation Classes) and Swing GUI components.

  • Java Look and Feel Design Guidelines
  • Java Look and Feel Design Guidelines (2nd edition)
  • Java Look and Feel Design Guidelines: Advanced Topics

  • KDE

    KDE originally stood for K Desktop Environment and is a popular Linux GUI.

  • KDE Human Interface Guidelines

  • Kinect

    Style guides for Microsoft’s motion sensing input devices.

  • Kinect Human Interface Guidelines

  • Macintosh

    These are some historical Apple GUI style guides, starting with Lisa in the 1980, and continuing to the “classic” Mac OS, with a brief stop in the Apple II corner.

  • Apple Lisa
  • Apple II
  • Human Interface Guidelines
  • Macintosh Human Interface Guidelines
  • Mac OS 8 Human Interface Guidelines

  • Mac

    More modern Apple Mac style guides, covering Mac OS X/Aqua and beyond.

  • Aqua Human Interface GuidelinesCovers early years of Aqua
  • Apple Human Interface GuidelinesCovers evolving Aqua
  • OS X Interface GuidelinesCovers the era between pure Aqua and Liquid Glass
  • Apple Human Interface Guidelines

  • Magic Cap

    An abandoned mobile operating system designed by General Magic.

  • Magic Cap Concepts

  • Microsoft Office

    Guidelines specific to Microsoft Office, in particular covering the use of its ribbon.

  • Microsoft Office System User Interface Design Guidelines

  • NeXTSTEP

    NeXTSTEP was NeXT’s influential operating system and graphical user interface. It eventually morphed into OpenStep on one side, and modern Mac OS X on another.

  • NeXTstep Concepts
  • NeXTSTEP User Interface Guidelines
  • OpenStep User Interface Guidelines

  • Newton

    Apple Newton was Apple’s PDA launched in 1993 and abandoned in 1998.

  • Newton User Interface Guidelines

  • Nokia

    Nokia released various style guides for its early smartphones, including its Symbian operating system.

  • The User Interface of Nokia 9110 Communicator
  • Nokia 7710 UI Style Guide
  • Series 40 UI Style Guide
  • Series 60 UI Style Guide
  • Series 80 UI Style Guide
  • Series 90 UI Style Guide
  • Hildon UI Style Guide
  • Symbian UI Style Guide
  • Symbian Belle UI Style Guide
  • Nokia N9 UX Guidelines

  • OPEN LOOK

    OPEN LOOK is a UNIX graphical user interface, started by Sun and AT&T.

  • OPEN LOOK: Graphical User Interface Functional Specification
  • OPEN LOOK: Graphical User Interface Application Style Guidelines

  • Palm OS

    Palm OS was the original graphical operating system for Palm’s mobile devices. Eventually, the company moved toward webOS, covered elsewhere on this page.

  • Palm OS User Interface Guidelines
  • Zen of Palm

  • PenPoint

    PenPoint was an early tablet operating system developed by GO Corporation for its unsuccessful line of devices.

  • PenPoint UI Design Guidelines

  • RISC OS

    RISC OS is a British operating system and GUI, developed originally for Acorn computers, and continuing as a community project.

  • RISC OS Style Guide

  • Samsung

    Various Samsung style guides.

  • The Samsung Gear UI Design Guidelines
  • One UI Design Guidelines
  • Samsung Smart TV Design Guides

  • Silicon Graphics

    Style guides for various UNIX-based operating systems from SGI, or Silicon Graphics Inc. Just like CDE above, these too use the Motif widgets.

  • SGI Indigo Magic User Interface Guidelines
  • SGI IRIX Interactive Desktop User Interface Guidelines

  • Sony Ericsson

    An early 2000s joint venture between two companies that made mobile phones.

  • Sony Ericsson UI Rulebook

  • Surface

    Style guides for first iterations of Microsoft Surface (today: PixelSense).

  • Microsoft Surface User Experience Guidelines
  • Microsoft Surface 2.0 Design and Interaction Guide

  • Taligent

    Taligent was a troubled software company, incorporated as an Apple/IBM partnership. One of its fruits was a CommonPoint application framework.

  • Human Interface Guidelines

  • webOS

    webOS was a successor to Palm OS that was eventually purchased by HP and later LG Electronics. Today, it is used on smart TVs, refrigerators, and projectors.

  • Palm webOS User Interface Design Guidelines
  • Palm Design Guide
  • HP Touchpad webOS Design Guidelines

  • Windows

    Does Microsoft Windows need an introduction? Note a little hole here around 1990, where Microsoft was preoccupied with CUA framework in partnership with IBM.

  • Microsoft Windows Software Development Kit Application Style Guide
  • The Windows Interface: An Application Design Guide
  • The Windows Interface Guidelines for Software Design
  • Microsoft Windows User Experience: Official Guidelines for User Interface Developers and Designers
  • User Experience – Official Guidelines for User Interface Developers and Designers
  • Windows XP Visual Guidelines
  • User Experience Interaction Guidelines for Windows 7 and Windows Vista
  • Windows 8–10 User Experience Guidelines
  • Design basics for Windows apps

  • Windows Phone

    Style guides for failed mobile Windows efforts, starting with Windows Mobile 6, and continuing through Windows Phone 7 and 8.

  • Designing Applications for Windows Mobile Powered Platforms
  • UI Design and Interaction Guide for Windows Phone 7
  • Design Library for Windows Phone 8
