I'm Full-Time Open Source Developer Now

Posted by

on under

People get surprised when I mention that I currently maintain not one, not two, but 18 open source projects. For most of my career I handled this work on the side of a day job, but with my day job now gone I am dedicating more time to open source. This is my attempt to advertise what I'm doing a bit better, in case some of you would like to support this work.

My 18 Open Source Projects

Maybe you did not know I have so many open source projects, or that I do open source work at all. If this is you, below is a list of all the projects I currently maintain, more or less grouped by area:

  • Extensions for the Flask framework
    • flask-migrate: Database migrations with SQLAlchemy and Alembic
    • flask-httpauth: Basic, digest and token authentication
    • flask-socketio: Socket.IO integration
    • flask-sock: WebSocket routes
    • flask-moment: Render dates and times in Jinja templates using moment.js
    • flask-paranoid: User session protection
    • apifairy: Automatic API documentation in FastAPI style
    • flask-pagedown: Markdown form control with preview
    • turbo-flask: Hotwire turbo.js integration
  • WebSocket
    • python-socketio: Python Socket.IO server and client
    • python-engineio: Engine.IO server and client
    • simple-websocket: Framework-agnostic WebSocket library
  • Microcontrollers
    • microdot: Minimalistic web framework for Python and MicroPython inspired by Flask
  • Databases
    • alchemical: SQLAlchemy wrapper for Flask, FastAPI and other web frameworks
  • Asynchronous programming
    • promisio: JavaScript-style promises for asynchronous applications
    • greenletio: Helpers to allow Python sync and async functions to call each other
  • Python helper libraries

Are any of these completely new to you? Feel free to check them out now!

Transitioning out of GitHub

The first large effort I have done with my newly acquired time is moving my projects to a self-hosted platform. I wanted to do this for a long time, but never found the time for something this big. What's wrong with GitHub? It has turned into a very annoying platform to work on, between the frequent outages, the constant UI glitches, and the way the platform encourages LLM users to submit low-effort pull requests that add little or no value but take a lot of maintainer time to handle. But don't worry, I'm not planning to delete my GitHub repositories, I'll just treat them as mirrors.

My projects now live at code.miguelgrinberg.com, and I'm populating the issues board with the tasks that I have on my roadmap, some of which have been delayed for years due to lack of time. Let me know if there is anything you'd like to suggest!

No more unsolicited pull requests

The most significant change in how I work on my open source projects now is that I have stopped accepting unsolicited pull requests. This does not mean that I'm not allowing collaborations, I'm just inserting myself in the process to add a little friction, which is sufficient to intercept the large volume of pull request slop that is common these days.

Are you interested in contributing something to one of my projects? I still want to hear from you if you are! Before I provide access you will need to reach out to me to discuss your proposal. But please keep in mind that I do not accept code that is generated with LLMs into any of my projects.

Funding my work

I know these are difficult times for a lot of people, but if you use some of my open source projects and benefit from them I would like to ask that you consider making a donation to help me continue doing this work.

You can make donations through any of the following platforms:

  • Buy me a Coffee: one-time and monthly
  • Github Sponsors: monthly
  • Patreon: monthly or yearly
  • PayPal: one-time
  • thanks.dev: for companies

If you use some of my open source projects in the company you work for, I would appreciate it if you talk to your management about providing corporate sponsorship.

Other ways to make contributions are by purchasing my books or by hiring me to work for you. If you want to support my work but none of the above options work for you please reach out and we'll figure something out.

Thank you!
