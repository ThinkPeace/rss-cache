Hyperlink selected text in Gmail Daniel Wirtz 11 months ago Copy link One thing I love about Notion, Slack and other modern apps is how easy it us to create a hyperlink: Copy the URL you want to link to Highlight the text you want to hyperlink Press Ctrl + V on Windows or cmd + V to paste it and voilà, it becomes a hyperlink Now, one could argue that it’s equally fast to use the icon or another shortcut, but I disagree. I have to constantly link to documents, websites and meeting links and this way it’s faster and more fun. Unfortunately, Gmail doesn’t support selecting a text and pasting a hyperlink on it. So the other day after work, I’ve put together a small web extension that adds this feature to Gmail. With Gmail URL paste, you can do the same as in Notion and Slack. Select some text, copy a link to your clipboard, then paste and it becomes a hyperlink. The extension is available for both Chrome and Firefox: Install on Chrome Install on Firefox
