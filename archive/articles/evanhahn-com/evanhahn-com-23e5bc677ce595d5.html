List of Vim forks

Here are the Vim forks I know about:

  • Neovim: “a Vim-based text editor engineered for extensibility and usability, to encourage new applications and contributions.”

  • Vim Classic: “a stable, long-term support fork of the ubiquitous text editor, maintained without the assistance of generative AI tools.”

  • EVi: “a hard-fork of Vim v9.1.0 (Jan 2024) before AI was used in the project.”

  • MacVim: “a macOS version of the Vim text editor, providing a graphical user interface for Vim, while tightly integrating with macOS and providing features specific to the platform.”

This list doesn’t include Vim-inspired editors like Kakoune, Vim-style plugins for other editors like IdeaVim, or Vim “distributions” like LazyVim.

Contact me if you know of other forks!
