There are other pages for books from Microsoft Press, which I didn’t bother to reproduce here.

A.L.D.S. is the Assembly Language Development System, a software development system for CP/M. muMATH/muSIMP was a lisp system disguised as a symbolic mathematics package. (muMath was the symbolic mathematics part; muSimp was the lisp part.)

I’ve talked about some of these products before:

  • Flight Simulator is probably Microsoft’s oldest continuing product. There was that time a customer reported an error in the map.
  • Access is a telecommunications program. The name was later reused for a database program.
  • FORTRAN was succeeded much later by Fortran PowerStation, which was not a resounding success.
  • The Mach 10 was not very successful either, but at least it did better than the Mach 20 for OS/2!
  • The source code for the Applesoft Compiler became shrouded in mystery. I have a follow-up to that story, but haven’t had time to research it and write it up.
  • The Microsoft Softcard was a plug-in board that you added to your Apple II to turn it into a CP/M system. It looks like a good number of programming languages were available in a Softcard edition.
