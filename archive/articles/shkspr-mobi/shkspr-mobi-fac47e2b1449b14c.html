I plugged a Zigbee dongle into my HomeAssistant box, but I couldn't find it in the UI. Here's how to get it working.

  1. Buy a USB Zigbee dongle
  2. Shove it in the computer running HomeAssistant OS (HAOS)
  3. On the command line of your computer, run lsusb
  4. Get the two IDs of your Zigbee device - for example 10c4:ea60 Silicon Labs CP210x UART Bridge
  5. In the same directory as your HAOS image, create a new file: sudo nano zigbee.xml
  6. Add the following
<hostdev mode='subsystem' type='usb' managed='yes'>
  <source>
    <vendor id='0x10c4'/>
    <product id='0xea60'/>
  </source>
</hostdev>
  1. Replace the 0x10c4 and 0xea60 with the IDs you got earlier (keep the 0x).
  2. Save the file with CTRL + X and then press Y
  3. Find the name of your HAOS install with virsh list
  4. Attach the Zigbee USB by running virsh attach-device haos --file zigbee.xml (replace haos with whatever you found on the step above)
  5. Reboot it with virsh reboot haos
  6. Wait a few minutes for everything to come back.
  7. Go to Settings → Devices
  8. The Zigbee device should show under "Discovered"
  9. Add the device and follow all the prompts.
  10. Restart HomeAssistant using Settings → ⋮ → Restart
  11. Start adding devices using Settings → Connectivity → Zigbee → Add device
  12. You will now need to make the USB attachment permanent.
    • Remove the USB device with: virsh detach-device haos --file zigbee.xml
    • Permanently attach it with: virsh attach-device haos --file zigbee.xml --persistent
