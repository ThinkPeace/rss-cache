Michael Steil:

Apple’s ill-fated Copland operating system is notoriously hard to run on real hardware, and has not previously been available in emulation. Here is the last build, D11E4 from June 1996, in an improved DingusPPC.

Playing around with the GXSlidemaster app, I found a bug. The keyboard shortcut for File → Print One is ⌥⌘P, but the menu manager displays it as ⌘π (because Option-P is how you type a lowercase pi; add Shift to get an uppercase pi (∏)). I should file a Radar.

Anyway, I don’t think I’ve ever used Copland before. It wasn’t just hard to run on real hardware, but hard to get. It’s fun but kind of gross to see it boot up spewing console detritus rendered in good old bitmapped Monaco 9 (inside windows — even as an early developer build Apple was still Apple). There’s really not much there there, though. The only work they’d accomplished was under the hood, and there’s seemingly nothing of actual interest in the user interface.
